# Rejected Olympic Sports

Entry for the [Rejected Olympic Sports](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da) bounty on make.fun.

One funny single-line sport the Olympics rejected — a made-up event, real enough to sound like a broadcast, absurd enough to be funny.

## The entry

> Synchronised queuing: four athletes stand perfectly still in a British post office queue, judged on patience, posture, and not sighing audibly.

## How it works

`main.py` (stdlib-only Python) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic — every run produces byte-identical output.

```sh
python3 main.py
```
